# 删除生成模块与移除墨绿界面

日期：2026-10-24。范围：按用户最新要求删除“AI古印生成”，去掉知识宇宙及相关馆藏目录的墨绿色视觉。

## 实际变更

- 删除 `Generate.vue`、`GenerateWorkbench.vue`，解除组件导入、页面映射及导航入口；原 `/generate` 深链重定向首页。
- 首页删除生成表单、风格和材质选择、生成按钮及灵感填词，使用已有馆藏搜索服务。按字寻印会检索真实条目。
- 删除规范字生成弹窗及定制页的生成入口；空作品入口改为上传印谱。实值和视觉示例两种模式均不显示该模块。
- 知识宇宙背景与展台为 `#0d0b09`，三维线条、粒子、标签与工具栏采用暖金色；平面图谱、统计条和目录同步去绿。官方照片、钤本和《千里江山图》图像未改色。
- 历史归档数据及训练、上传、图像处理能力保留，不把普通排版或 STL 结果描述成已训练的篆刻生成。

## 已验证

1. 浏览器访问 `/generate` 返回首页；侧栏与首页无生成模块文字或 `/generate` 链接，切换到视觉示例模式也不会恢复。
2. 首页搜索“大府”实际返回 1 / 125 条馆藏记录，跳转参数为 `q=大府`；记录链接指向已核对的馆藏节点。
3. 点击三维展签“大清受命之宝”会更新官方图片、故00167102、钤本和对应故宫原文链接。平面研读与三维游观可切换。
4. 桌面 1620×911，手机 388×844；手机首页与图谱均无页面横向溢出。实测背景为 `rgb(13, 11, 9)`。
5. 编辑期间的热更新曾捕获删除组件过程中的临时导入错误；最终新加载的首页和手机图谱控制台均无错误。
6. 27 项既有前端检查通过，最终 TypeScript 检查与生产构建通过。本轮未更改后端行为，未重复运行后端测试。

证据保存在 `evidence/remove-generation-blackgold-20261024/`，包括最终页面截图、检索截图、构建和测试日志。该验收仅针对本次删除与配色修改，不代表全站像素级复刻完成。
