按文件名中的书名和页号分组，用固定哈希划分；按解码RGB像素哈希排除完全重复。不同页仍可能来自同一本书，尚未排查近重复与同印多次扫描，不能称作跨馆藏泛化评测。此次目录内没有非图片文件，未发现释文、字符框或完整图配对；没有把文件名或自动模型输出当文字标签。

`data/raw-crops-audit/`包含summary、全量manifest与三组JSONL，均记录文件SHA256。`contact-sheet.png`为随机30张本地素材概览。`annotation-seed.csv`从验证集抽取100张，释文、框、掩膜和完整图路径均留空、verified=false，供人工标注，不是现成真值。该CSV来自验证组，不能用于训练；若需用于训练，须发布新的按来源分组划分版本并重建评估集。

本轮GPU实验从各组抽取2,048/128/128张，以原始有损裁图为目标，只添加高斯噪声。原有缺损没有被补齐，也没有OCR监督。见GPU_TRAINING.md。目录内未发现来源许可说明；素材留在本机，交付包仅包含清单与少量核验预览，不代表已取得公开再分发或商用授权。

复现审计（在项目目录，使用具备Pillow和NumPy的Python）：

```powershell
python backend/training/audit_dataset.py --source D:/LH/raw_crops --out data/raw-crops-audit
```

输出目录必须位于原始素材目录之外。防源文件改动、同页分组、完全重复/损坏/过小图片处理共有3项自动检查，已通过。
