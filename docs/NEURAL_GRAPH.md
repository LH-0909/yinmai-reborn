# 三维资料星图 · 2026-10-22

打开 [沉浸式知识图谱](http://127.0.0.1:5173/graph)。桌面默认进入沉浸视图；手机默认使用常规页面，也能点“沉浸式空间”。本机服务未启动时，双击项目根目录的 `Start-Web.cmd`。已有环境的启动、状态和停止操作由 `scripts/dev.py` 管理，首次在另一台电脑运行仍需按README配置依赖和MySQL。

## 已实现

- Three.js真实三维场景、青蓝发光节点、Bloom泛光、透视网格和环境尘埃；支持拖动旋转、滚轮缩放。
- 关系曲线上移动的光流；桌面全图756个粒子，手机及文化页嵌入视图降低粒子数。每个粒子都对应返回数据中已有关系的ID，不额外生成关系。
- 悬停显示名称、类型和当前关联数；点击节点或标签聚焦并显示资料，点击连线查看关系与页面证据。
- 节点分组目录、搜索、来源、类型和状态筛选，以及一层／二层／全部节点范围。点击“围绕此节点展开”显示该节点邻域。
- 保留中心辐射、分层结构两种二维布局，随时切换。三维初始化失败时提供二维入口。
- 保留当前筛选的真实统计、资料路径、候选导入与核验、JSON／RDF／JSON-LD导出。
- 文化溯源页切换“本机实值”后，中央使用同一三维组件；点击可直达对应节点或关系详情。原有其他展示区域继续保留视觉示例标记。

界面按钮“暂停光流”同时冻结尘埃与网格脉动，旋转和点击仍可操作。系统偏好减少动画时初始暂停。切走浏览器标签后停止绘制，组件卸载时释放场景、后期处理、标签和监听器。

## 数据与表达范围

仍使用现有MySQL接口和公开页面的文字字段：61个节点、126条关系、18份读取凭证，15个页面直接支持关系。空间位置是显示布局，不能解释成年代、可信度或历史传承；光流也不代表实时活动。未填造人物、作者、朝代、训练标签或整库馆藏。复旦“印藏”仍只有入口及首页凭证，条目目录尚未接入。具体来源见 [有据知识图谱](KNOWLEDGE_GRAPH.md)。

现有项目没有ECharts依赖，本次保留的是原有统计区与真实数字，没有把已有装饰图表声称为ECharts交互图表。原八页的严格像素一致验收仍未通过，见 [原八页报告](design-qa-eight-pages-20261022.md)。此次用户选择的是新的三维图谱视觉方向，并非八张原图的像素相等版本。
