## 真实访问的主要来源

- [故宫《玺印》概述和公开目录](https://www.dpm.org.cn/collection/seals.html)：读取27页公开索引，获得314条目录行；从实际链接中分散选取150条详情，119条通过字段与图像匹配，31条隔离。与原3条核心记录合并、去重后为120条故宫记录。公开页面脚本所用的目录 AJAX 同样记录请求地址、哈希和读取时间，不称为登录后数据库访问。
- [中国国家博物馆“皇帝之宝”玉印](https://www.chnmuseum.cn/zp/zpml/csp/202111/t20211126_252412.shtml)、[“君之信玺”玉印](https://www.chnmuseum.cn/zp/zpml/csp/201812/t20181218_28017.shtml)、[“滇王之印”金印](https://www.chnmuseum.cn/zp/zpml/kgfjp/202110/t20211028_251978.shtml)：只列选定的3条官方藏品页。保留正文原字“君之信鉩”。滇王之印原页的学术解释不提升为系统独立结论。
- [南越王博物院“文帝行玺”龙钮金印](https://www.nywmuseum.org.cn/Collection/Details/?nid=47)、[“右夫人玺”金印](https://www.nywmuseum.org.cn/Collection/Details/dcjp?nid=67)：读取对应条目与页面主图。

国博、南越5条未取得公开文物号，保持 `accession_number` 为空；真实网页条目号标成“官方条目号（非文物号）”。故宫旧图与新图可能使用不同标题后缀，如“印/玺”；只接受同一藏品画廊中完整引号印文一致的受控情况，界面保留题名、图片说明及差异提示。

## 页面已经补充的内容

- `/`：125条记录、18个时代浏览分组、8名具名制印人、170份来源凭证，实时读取后台；使用当日日期与有明确出处的短引文。默认精选为真实馆藏图像，旧图中烘焙的125800等示例数值不进入真实数据卡片。
- `/catalog`：每页6条，共21页；机构、时代、文物号、印文、制印人检索；支持“鉩”等原字；照片/钤本缺项明示；20条论著目录可展开。
- `/culture`：默认改为来源分期、真实条目、差异入口和论著目录。虚构谱系、示例事件、地域统计只在明确的视觉示例模式中保留。
- `/graph`：125条馆藏记录进入受控主展区；点击查看官方身份、节录、原始出处、差异和目录制印人。沿字关联最多同时显示8条相关馆藏，完整匹配可转目录查看。共享文字不解释为同一作者、时代或风格。

## 证据门槛

发布清单和图数据库必须同时匹配条目身份、官方URL、来源平台、正文SHA-256、读取时间、已记载的馆藏关系。普通线索导入禁止直接创建真实 `seal_object`。改名、改编号、缺凭证或候选状态都会被主展区排除。论著目录也验证读取凭证，不把手工引用视为已读取全文。

125张主图和106张钤本均校验本地SHA-256；122条新增记录的缓存HTML与目录字段凭证另行逐条比对哈希，原3条核心凭证保持原版。23张跨馆、跨期样本联系表已经人工查看；这不是对全部文物的专家鉴定。

## 可重现采集

运行环境需要Python和项目依赖中的Pillow。三步均只处理明确允许的公开馆藏网址；不需要账号，不执行网页JS，不绕过验证码。

```powershell
python scripts/harvest_official_seals.py --images --limit 150
python scripts/collect_cross_museum_records.py
# 核对 runtime/heritage-harvest/records-stage.json、隔离项和图像后发布
python scripts/publish_heritage_batch.py
```

采集器限制体积、像素、并发和访问频率；失败保留为缺项或隔离，不降低SSL验证。原始HTML与采集缓存留在 `runtime/heritage-harvest/`，不随源码包分发。发布脚本生成 `data/heritage/`、独立图谱扩展种子和本地图像清单；MySQL重启幂等写入，不覆盖人工复核。旧三条采集器发现已有发布目录后会拒绝覆盖，避免把125条误写回3条。

本轮原始缓存位于开发工作目录，并没有移动或改写用户的13,646张原始素材。官方图像供本机带出处研读，未宣称取得公开商用或模型训练许可，也没有拿它们训练字体模型。
