# 《方寸千年》三分钟讲解稿

> 用途：C3 信息可视化赛道 3 分钟演示视频配音 / 现场讲解。
> 口径：只讲系统真实具备的能力。识别与修复模型当前未接入权重，稿中明确说明，不冒充 AI 成果。
> 台词共 613 字，按 3.5 字/秒约 2 分 55 秒，加三处停顿正好 3 分钟。

## 逐字稿

**【0:00–0:18 · 开场】**
（画面：首页全屏，缓慢推近主视觉印章）

> 一枚印只有几厘米，却压着两千年的重量。今天要给你看的，不是一个印章展览网站，而是一张能读、能查、能走进去的印学星图。我们先从一方真实的印开始。

**【0:18–0:50 · 是什么】**
（画面：首页四个统计数字依次亮起；右侧「今日印语」轻轻上移）

> 印脉重生接入了故宫、中国国家博物馆、南越王博物院三家机构的 125 方官方馆藏，170 条来源凭证，每一条都能回到官方原页；18 个时代分组、8 位具名制印人，全部来自条目原文。在这批真实资料之上，我们建了一张 555 个节点、1013 条有据关系的知识图谱。

**【0:50–1:45 · 演示一：检索与读印】**
（操作：目录页搜索框输入「之」→ 回车 → 结果刷新 → 点开一条分期冲突的记录）

> 先看检索。输入一个「之」字，系统在官方释文里逐条比对：20 方印，从战国排到清光绪。每一条给出时代、材质、尺寸、制印人，还有一个不能省的按钮——官方原文。分期有冲突的，我们不合并、不猜，标成「分期待核对」并列保留。点进任意一方，看到的不只是图片，而是它在图谱里的位置：哪个时代、什么书体、被哪本文献收录。

**【1:45–2:22 · 演示二：有据图谱】**
（操作：进入图谱 → 入卷 → 点一个「之」字节点 → 点一条边看文档 → 做一次路径查询）

> 这是系统的核心：一张有据关系图。每个节点都是一条真实资料，每条边都挂着一份文档。从一个「之」字，可以走到一方汉印，再走到制印人；也可以选两个节点，查它们之间最短的资料路径。这条路径只说明共享书体或汉字，不构成传承关系——这条边界写在图上，也写在文档里。

**【2:22–2:50 · 技术闭环】**
（操作：工作台 → 上传一张印谱 → 提取 → 三维重建 → 旋转 STL）

> 图谱之外，系统还往下走了一步：OpenCV 提取印文，参数化生成封闭的 STL 印面，毫米尺寸，可导出、可打印。需要如实说明，深度识别与修复模型没有接入权重，页面上就显示「不可用」——我们不用假结果充数。

**【2:50–3:02 · 收尾】**
（画面：回到画卷或首页，定格在两行字上）

> 让古印被看见，也被读懂，还能被重新刻出来。系统已经在线，欢迎各位老师现场检索任何一方印。

## 答辩备用五问

**1. 你们的 AI 在哪？**
识别与修复的 TorchScript 权重尚未提供，接口会明确返回「未配置」，页面不生成假结果。目前可验证的是 OpenCV 图像处理、参数化建模与图谱关系。

**2. 125 条数据怎么来的？**
故宫 120 条、国博 3 条、南越王 2 条，均来自官方公开页面，逐条保存页面地址、抓取时间与页面 SHA256，共 170 条来源凭证；20 条文献目录标明「全文未核读」。

**3. 和普通博物馆网站有什么区别？**
普通站点按藏品陈列，这里按关系组织。任选两个节点可查最短资料关联路径，每条关系挂着具体文档，能追到出处。

**4. 版权怎么处理？**
图像仅用于教学与研究展示，保留官方原页链接；用户提供的 UI 参考图单独标注，不作为文物证据。

**5. 三维真的能打印吗？**
生成的是印面浮雕 STL，做过封闭网格与法线检查，单位毫米；狮钮雕塑与原器复原不在当前能力内，不做宣称。
