# 图像增强与人工标注实验室

用户已确认目前只有裁图，没有释文/字符框/完整图配对。本轮实际新增页面：http://127.0.0.1:5173/lab 。可从项目管理的“增强与标注”或图像处理页底部进入。它是独立的扩展工具，原有9个参考页面继续保留。

## 实际可用

1. 从已审计验证组的100张候选中预览、载入单张原图。后端核验SHA256，并限制路径在本机配置目录内；原始图片不移动、不改名、不覆盖。相同文件再次载入会复用已入库印谱。
2. 对当前原稿实际运行自训TorchScript去噪模型，保存独立`enhancement`版本、来源、模型哈希和实验限制。训练使用GPU，当前Web服务推理使用CPU；单张裁图边长须不超过512px。未自动添加噪声，不伪造“真实噪声去除准确率”。
3. 人工填写可见文字、辨认情况和疑问，或留空。画布始终绑定原始扫描，可启用手绘笔刷并逐笔撤销。青色是画布叠层，导出为白色印迹、黑色背景的单通道PNG。
4. 填写标注人后保存。JSON记录原稿ID与SHA256、归一化笔迹、可见文字与草稿状态；手绘掩膜单独保存。没有笔迹时明确记录“未标注”，不生成空白真值。
5. 重新进入或重载可恢复最新已保存草稿；新保存会创建版本，保留旧文件。下载按钮可导出JSON和掩膜PNG。草稿修改未保存时，页面内切换会提示继续编辑或明确舍弃。

连续保存的版本时间保留微秒，避免同秒排序读回旧草稿。已有早期数据库需先备份，再应用`backend/migrations/002_microsecond_timestamps.sql`；本机已执行且前后记录数量一致，备份只存于工作目录，不打入交付包。历史只有秒精度的记录不会凭空推断细分先后。

所有记录均为`review_state=draft`、`ground_truth_verified=false`、`auto_use_for_training=false`。增强结果不会自动进入释文字段，也不能替代原稿作为人工标注来源。暂不支持字符框、专家双人复核、正式标注发布或完整修复真值制作。

## 本机配置

本机`.env`已配置`TRAINING_CORPUS_PATH=D:/LH/raw_crops`。源码包的`.env.example`只保留空变量，不含私密凭据；在其他机器填自己的素材目录，并保留或重新生成审计清单。没有素材目录时仍可上传自己的裁图使用实验室。

`data/raw-crops-audit/annotation-seed.csv`为100张验证组候选的空白模板。候选数量和“已载入”是实际数据库统计，不代表完成标注。100张候选保留验证组身份；标注数据不会自动加入训练。若未来改变用途，须发布新的分组版本并建立独立测试集，避免评估泄漏。

去噪依赖`backend/requirements-ai.txt`中的CPU PyTorch及交付包内自训权重；运行环境不存在时状态与接口明确不可用，不回退到伪造结果。Docker配置默认不含PyTorch，本机Docker路径仍未测试；使用该路径需安装可选AI依赖并挂载模型。

## 证据与限制

34项真实MySQL测试覆盖原有流程与新增增强、模型缺失、原图哈希、标注版本、空释文不补写、手绘二值掩膜、非法坐标、素材目录范围与防篡改。本机浏览器实际载入`tzsf_yt_p0186_01.png`并运行增强；人工草稿保存/重载和单点笔迹导出使用明确标识的合成测试图，仅为功能验证，不是专家释读或有效掩膜真值。真实候选的释文保持空白。

训练记录中的`api_model_enabled=false`是导出当时的状态快照。此后新增了本页的独立实验接口；正式`RESTORE_MODEL_PATH`与OCR仍未启用。实验去噪不补已缺失的历史笔画，没有真实损伤修复质量结论。

训练图片已另行补包并提供完整浏览入口，详见TRAINING_IMAGES.md。新增完整包的training-data/支持自动发现，或用ANNOTATION_SEED_PATH指定相对路径候选清单。
