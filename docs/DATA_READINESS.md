## 当前应做的工作顺序

1. 核对素材类型，区分整方印章、单字和其他内容；检查坏图、过小图片和疑似视觉重复，原图始终保留。
2. 选定一个有依据的目标印风，人工检查样本是否一致。不能因为同属一本印谱便自动归为一种字体。
3. 先做少量单字样本，确定框选、释文、朱白文、镜像和异体字记录规则。存疑字保留备注，不填猜测标签。
4. 核对重复样本与同字关系，再确定字体训练、验证、测试的正式划分。现有按汉字固定划分的训练入口仅是工程基线，实际研究评估还需明确来源与风格的独立性。
5. 标签与划分通过检查后才训练印谱风格模型，并测试未见字、细笔画、错字和风格一致性。

整理可以由程序辅助；释文、异体和印风归属需要可靠核对。此阶段没有必要先让用户手动建立train/test文件夹，也不应立即对全部原始素材做字体训练。
