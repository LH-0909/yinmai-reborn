# 青绿画卷入口 · 2026-10-23

`/graph`新增真实Three.js卷轴展陈：双轴展开、纸面轻弯、沿全卷数字摹本移动的局部窗口、缓慢光尘、暂停/重播、手动游标、来源说明与直接读印。条目深链直接读印，可选择“画卷入境”；125条官方馆藏和原工作台继续可用。

绘画身份依据[故宫王希孟千里江山图卷官方条目](https://www.dpm.org.cn/collection/paint/228354.html)，文物号新00146004。全卷纹理来自[Wikimedia Commons数字摹本](https://commons.wikimedia.org/wiki/File:Wang_Ximeng._A_Thousand_Li_of_Rivers_and_Mountains._(Complete,_51,3x1191,5_cm)._1113._Palace_museum,_Beijing.jpg)，源站标注Public Domain Mark/PD-Art；备用局部图来自故宫官方页。原始字节哈希、源URL和两个WebP预览的哈希在`frontend/public/assets/landscape/source.json`。

源摹本39974×1600，供Web使用的两份缩略图为16000×640与8192×328；不生成新画面，不把局部动态窗口称为完整原作原样展示。通用卷轴、灯光和纸面运动是展陈设计，不代表原作结构、历史状态或文物三维扫描。绘画没有混入125条印章馆藏统计，也未凭画上的同名鉴藏印虚构与现有印章实物的关系。

组件离开视窗、页面隐藏或手动暂停时停止动画；卸载释放纹理、几何、材质及观察器。系统减少动态效果时初始静态；WebGL失败显示官方局部图并保留读印入口。后两项本轮完成实现，未强制故障测试。

已实际查看桌面完整展开与展开中间状态、暂停/播放、重播、直接读印和条目深链；实测388×844手机画卷无横向溢出。当前生产构建通过，控制台抽查未见警告/错误。画卷是可运行开发版，整体审美和布局仍有P1/P2项，见[客观自检](PRODUCT_AUDIT_20261023.md)。
