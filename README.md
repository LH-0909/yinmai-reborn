## 已验证的操作

1. 在“印谱上传”选择 PNG/JPEG/WebP，或点击明确标识的“导入合成测试样本”。后者仅供验证，不是历史文物。
2. 在“AI智能识别”生成实际印文提取版本。此操作是 OpenCV 图像处理，不是古篆字识别。
3. 在“AI修复”调整去噪、笔画连接和镜像，生成实际处理图。原稿保留，每个版本记录来源、参数与 SHA256。
4. 确认版本，在三维页选择该图像来源，设置朱文/白文、镜像、毫米尺寸、浮雕高度，生成实际 STL。
5. Three.js 直接加载这个 STL，可旋转、缩放、切换材质和线框，并下载同一个真实文件。
6. 制作页记录人工网格检查、镜像检查和是否实际试盖；记录写入 MySQL。没有接入打印机，没有假称已完成实物制作。
7. 项目管理显示数据库实值、版本、改名和操作时间线。知识库查询4条有来源的基础知识及真实上传档案。

旧处理工作台顶部“界面参考（不可处理）”仅展示提供的UI素材，操作按钮禁用。素材中的狮钮雕塑不是本系统生成的模型。三维功能实际生成的是印面浮雕，历史原器复原与狮钮雕塑不在当前算法能力内。

## 在其他设备运行

### Docker组合

需要 Docker Engine/Compose。复制 `.env.example` 为 `.env`，填入自己生成的 `MYSQL_PASSWORD`、`MYSQL_ROOT_PASSWORD`。然后执行：

```sh
docker compose up --build -d
```

访问 http://127.0.0.1:5173/ 。数据库与图像通过命名卷持久保存。不要使用 `docker compose down -v` 删除需要的项目数据。Docker配置已提供，但本机没有Docker，**本次未运行该路径**。

### 本地工具链

需要 Python 3.12、Node 20.19+或22.12+、pnpm、可访问的 MySQL 8.4。

```sh
python -m venv .venv
# Windows
.venv\Scripts\python -m pip install -r backend/requirements.txt
# Linux/macOS
# .venv/bin/python -m pip install -r backend/requirements.txt
```

若本机pip配置强制user安装，先在当前PowerShell会话设置 `$env:PIP_USER='false'`，再安装。Windows临时目录若拒绝访问，把当前会话的 `TEMP` 和 `TMP` 指向项目内已创建的 `runtime/tmp`，不需要修改系统权限。

由 MySQL 管理员创建 `yinmai` 数据库及项目账户，只授予该库的读写、建表和索引权限；在 `.env` 配置对应连接。后端拒绝回退到 SQLite 或 Mock。启动时自动建表；当前为初始开发模式，正式升级需要数据库迁移方案。

```sh
.venv\Scripts\python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

另开终端：

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1 --port 5173
```

构建：在 `frontend/` 执行 `pnpm build`，会进行TypeScript检查并生成 `dist/`。`pnpm-lock.yaml` 固定本次验证依赖。`backend/requirements-verified-windows.txt` 保存本机完整版本清单；它包含Windows及可选PyTorch依赖，不应直接当作跨平台锁文件。
